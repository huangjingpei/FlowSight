## 1. 简介与系统定位
本系统是基于 FlowSight 边缘 AI 采集端构建的**云端多租户客流分析运营中台**。系统提供人流通行人数统计、性别、年龄结构分析、实时视频切片回溯、多点位管理与移动端看板展示。
- **采集端 (`FlowSight C++ 客户端`)**：边缘端实时分析多路 RTSP/本地流，执行 YOLOv8 + ByteTrack 多目标追踪、性别年龄推断、ROI 通行判定，产生短切片并上报云端；
- **业务中台 (`solution/backend`)**：基于 **Spring Boot 3 + MySQL 8.0 + Redis + MinIO**，负责租户管理、点位管理、流水落库、切片存储与统计分析；
- **移动与管理端 (`solution/apps`)**：
  - `apps/h5`：基于 **Vue 3 + Vant** 的商户移动端决策看板，支持多点位流切换与切片秒级回放；
  - `apps/admin`：基于 **Vue 3 + Element Plus** 的运营管理后台，支持管理员对用户与点位资产的统一管控。

---

## 2. 用户角色与权限体系
1. **超级管理员 (`ROLE_ADMIN`)**：
   - 全局运营看板：全网点位数目、商户用户数目、在线设备与总人流通行大盘；
   - 用户管理：开通商户账号（指定手机号，默认密码同手机号，直接分配初始点位）、修改与封禁商户、级联删除用户（物理清空其名下点位与视频切片）；
   - 点位审计：跨用户检索各点位摄像头参数与运行健康度。
2. **商户/业主用户 (`ROLE_USER`)**：
   - 凭据体系：手机号码 + 密码；
   - 移动 H5 决策看板：查看名下点位的人数、年龄分布、性别比例、小时趋势；
   - 采集客户端互认：支持使用该手机号密码直接登录 FlowSight 现场客户端，或通过手机 H5 扫码秒级授权登录并绑定点位。

---

## 3. 点位管理与多点位流切换机制
1. **点位资产维护**：针对每个商户用户进行点位信息的增删改查：
   - **新增点位**：配置点位名称、物理地址、摄像头 RTSP 地址、视频分辨率等，系统自动生成专属接入 `Point-Token`；
   - **删除点位**：逻辑注销点位，并触发异步任务清空云端历史通行事件及 MinIO 切片池文件。
2. **移动端单流互斥切换与播放锁定状态机**：
   - 商户名下拥有多个点位（流）时，手机 H5 顶部提供下拉切换，一次仅聚焦展示一个选定点位的数据看板；
   - **核心约束（播放锁定）**：当用户在手机端点击某条通行记录播放视频监控切片时，系统自动锁定点位切换功能（Disable 切换下拉框），防止视频串流与数据时序混乱；关闭视频后自动解除锁定。

---

## 4. 视频片段回放流转机制 (方案 A 落地)
- **切片生成**：FlowSight 现场采集端在发生通行事件时自动截取事件发生前后 2 秒（共约 4 秒，体积仅 1~2 MB，H.264 编码）；
- **轻量转存**：边缘端生成切片后，异步非阻塞上传至云端对象存储（MinIO / OSS），云端记录访问相对路径；
- **H5 秒开回放**：手机端 H5 点击事件记录流水时，中台签发带有效期的直链 URL，手机端通过原生 HTML5 `<video>` 直接流式播放，彻底解决传统局域网 P2P 在 4G/5G 移动端高穿透失败率的痛点。

```text
solution/
├── backend/                              # Spring Boot 3 + Java 17 + MySQL 8.0 + Redis + MinIO
│   ├── src/main/java/com/flowsight/cloud # 核心业务代码 (Auth, User, Point, Event, Ingest, H5)
│   └── src/main/resources/schema.sql     # 完整数据库建表脚本
```
