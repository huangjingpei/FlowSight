# FlowSight 移动端 UI 交互深度重构与 5 秒动态流速曲线及系统设置演进报告

## 1. 用户反馈复盘与产品交互升级意图

用户明确指出：
> 1. “首先实时座舱，并没有反应当前点位的人数以及统计信息的变化，更没有一个实施的类似于动态曲线绘制的过程，这里其实是一个近乎实时的一个刷新，可以做到5s一次等这样的操作，客户端并不关心边缘的的一些信息，只要有地方能能够显示边缘在线和掉线就可以了。”
> 2. “实时走势页面,你的表太差了，横轴，纵轴，至少有方向，有刻度等，甚至有浅色的网格，这些你都没有。”
> 3. “客户画像页面，真的需要吗？有没有一些设置之类的，可以做个系统设置，类似于设置页面，比如修改密码，等等，你可以结合现在的功能，甚至可以把客户画像里的东西，放到系统设置的某一个条目下面”

## 2. 核心交互与架构演进方案

### 2.1 实时座舱（Dashboard）：剥离无关遥测，引入 5 秒级动态流速心跳曲线
1. **轻量化边缘感知**：
   - 终端商户无需关注边端 C++ 推理时延（14.2ms）或模型结构，顶栏仅保留简洁醒目的 **`● 边缘在线`** 或 **`○ 边缘离线`** 状态标签；
2. **5 秒近实时动态轮询（5s Real-time Pulse）**：
   - 前端设立 5 秒定时器轮询最新统计增量，大字号呈现瞬时在场、累计进入、累计离开、双向总流；
3. **实时通道流速脉冲折线图（Dynamic Pulse Waveform）**：
   - 在座舱下半区开辟高反差动态脉冲图，以 5 秒为一个时间步进点，实时推入最近 12 个时间片段的进出人流动量；
   - 进出流速动态起伏波动，如心跳般生动反映通道行人通行节奏，彻底解决画面静态死板的问题。

### 2.2 时序走势（Trends）：高水准工业级图表标准化
对 ECharts 时序走势图进行了全要素专业级完善：
1. **X 轴（时间轴）**：
   - 增加**末端方向指示箭头**（`symbol: ['none', 'arrow']`）；
   - 标注坐标轴物理量名称：`时间 (HH:mm)`；
   - 增加精确与刻度标签对齐的**细刻度线**（`axisTick`）；
   - 增加浅色精细虚线纵向背景网格（`splitLine`）；
2. **Y 轴（流量人次轴）**：
   - 增加**垂直向上方向指示箭头**；
   - 标注物理量名称：`通行人次 (人)`；
   - 增加 Y 轴**细刻度线**与整数步进（`minInterval: 1`）；
   - 增加浅灰色横向虚线背景参考网格（`#1F293D`）。

### 2.3 导航演进：重构 Tab 4 为“系统设置与商户中心”
将独立的客群画像页面演进为 **系统设置（`/settings` Settings.vue）**，功能分流更为合理实用：
1. **商户认证资料卡**：展示万科物业商户名称、绑定手机号与认证角色；
2. **账号登录密码在线修改**：
   - 前端提供原密码、新密码、确认新密码交互表单；
   - 后端新增 `POST /api/v1/h5/user/password` 接口，基于 Spring Security `BCryptPasswordEncoder` 完成安全验签与密码哈希更新；
3. **客群属性洞察条目**：将性别比例双色条、主力到场年龄段、AI 置信度折叠收纳在设置条目中，支持一键展开查看；
4. **边端连接与通道管理**：通道名称、点位 ID、边缘节点名称、心跳时间戳；
5. **实时座舱刷新频率偏好**：支持商户在 `5秒 (近实时推荐)`、`10秒 (标准)`、`30秒 (省流)` 间快速切换并本地持久化；
6. **安全退出账号**。
