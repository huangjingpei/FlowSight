# FlowSight 智能座舱数字孪生大屏重构与真实采集时序动态曲线实施报告

## 1. 痛点问题复盘与设计意图

在早期的 H5 监控看板中，存在两个严重影响体验与工业落地交付的痛点：

1. **时序图表失真与死板（“绘制的是什么玩意？”）**：
   - **根本原因**：原时序接口强制生成 $00:00 \sim 23:00$ 的 24 小时绝对固定桶。当边缘节点（FlowSight.exe）在某一个时间点上报数据时，图表在 `00:00` 处出现断崖式的尖峰，而后面的 23 个未来小时全部补 `0`。
   - **业务不合理性**：不仅浪费了宝贵的屏幕展示空间，更掩盖了边缘摄像头实际采集到行人的真实发生时间（`occurred_at`），用户无法获知“几点几分有几个人通过”。
2. **视觉风格扁平沉闷，缺乏高级感（“没有一点智能座舱高级感”）**：
   - **根本原因**：原界面采用普通灰黑色块与默认组件，在 1080P/2K/4K 桌面浏览器中全屏失真拉伸（ECharts 宽度达到 1900px，高度仅 260px，曲线压平如直线）；缺乏环境氛围光、全息玻璃质感、雷达呼吸动效与高辨识度赛博配色。

## 2. 核心技术改造方案

### 2.1 后端：基于物理通行事件发生时间（`occurred_at`）的自适应动态时序聚合引擎

在 `com.flowsight.cloud.service.impl.EventServiceImpl` 中对趋势时序统计逻辑进行了全面重构：

```
[客户端请求: dimension=realtime & pointId=2]
                      │
                      ▼
[检索 biz_passage_event 当日真实采集通行事件]
                      │
                      ▼
[计算物理时间跨度 (Span = MaxTime - MinTime)]
                      │
        ┌─────────────┴─────────────┐
        │                           │
  Span <= 15分钟              Span <= 2小时              全天跨度
  [1分钟高精桶]               [5分钟自适应桶]            [30分钟宏观桶]
        │                           │                           │
        └─────────────┬─────────────┴───────────────────────────┘
                      │
                      ▼
[提取真实HH:mm采集点] ──> [动态累计进入/离开数量] ──> [输出自适应时间轴]
```

- **真实采集时序模式（`dimension = "realtime"`）**：
  - 直接从 `biz_passage_event` 物理记录中抓取当日发生的通行流水，按实际事件时间 `occurred_at`（或 `reported_at`）精准聚类。
  - **自适应时间分桶算法**：
    - 若时间跨度 $\le 15$ 分钟：以 **1 分钟** 为步长生成时间轴，精准呈现每分钟的人流微动。
    - 若时间跨度 $\le 120$ 分钟：以 **5 分钟** 为平滑步长。
    - 若时间跨度 $\le 360$ 分钟：以 **15 分钟** 为步长。
    - 全天跨度：以 **30 分钟** 为宏观步长。
  - **杜绝未来小时补零**：时间轴的终点以当前实际时间或最新采集事件时间为上限，不再绘制虚假的未来零值。
- **逐时模式防断崖截断（`dimension = "hour"`）**：
  - 传统按小时查看时，自动根据 `LocalDateTime.now().getHour()` 进行右边界截断，当前是几点就展示到几点，杜绝下午或夜间的无效平地。

### 2.2 前端：新能源智能座舱（Smart Cockpit HUD）数字孪生视觉重构

前端重构了 `solution/apps/h5/src/views/Dashboard.vue`、`App.vue` 及 `Playback.vue`：

1. **宇宙深空黑曜石底色与径向青靛光晕**：
   - 背景使用 `#060911`（深空晶体黑），配合 `radial-gradient` 多层光场（青色 `#0ea5e918` 与靛紫 `#6366f112`），营造新能源豪华座舱中控屏的环境氛围沉浸感。
2. **中心化数字座舱底盘结构（Chassis Constraint）**：
   - 增加 `.cockpit-shell` 与全局悬浮底栏约束：`max-width: 520px; margin: 0 auto;`。
   - 在 1920x1080 甚至 4K 显示器上，呈现如同 Tesla / 蔚来智能座舱仪表盘的高端中控掌机形态，杜绝无节制拉伸导致的图表扁平变形；在移动端则自适应填满全屏。
3. **四维全息磨砂玻璃仪表盘（Holographic HUD Tiles）**：
   - 4 个核心 KPI 指标卡采用双层磨砂玻璃质感（`backdrop-filter: blur(20px)` + 微细内发光边框 `inset 0 0 16px`）：
     - **瞬时滞留（Electric Cyan `#22d3ee`）**：带雷达动态呼吸脉冲灯（Radar Pulse Ring）。
     - **累计进入（Mint Aurora `#34d399`）**：极光薄荷绿，代表顺畅涌入。
     - **累计离开（Cyber Amber `#fbbf24`）**：赛博琥珀金，代表安全通行。
     - **双向总流（Ultraviolet `#c4b5fd`）**：紫外霓虹光，代表综合吞吐通量。
4. **赛博霓虹双色样条曲线图表**：
   - **进入流线**：电动青光 `#00f2fe`，带 `0.45 -> 0.00` 霓虹渐变投影面积。
   - **离开流线**：珊瑚粉红 `#ff5e7e`，带柔和垂直羽化渐变。
   - **HUD 悬浮微晶 Tooltip**：半透明毛玻璃悬浮卡片，显示精确到分秒的采集点进出流量。
5. **智能采集时序胶囊切换器（Time Dimension Capsule Pills）**：
   - 默认选中 `⚡ 实时采集时序`，一键可切换 `⏱️ 今日逐时`、`📅 近7天走势`、`📊 近30天走势`、`🌐 季度宏观`。

## 4. 验证效果总结

1. **真实采集时序生效**：
   - 边缘端 `FlowSight.exe` 采集上报通行数据后，看板时序图准确落在上报的分钟区间内，不再堆积在 `00:00`，曲线自然起伏展现真实人流高低峰。
2. **智能座舱视觉体验大幅提升**：
   - 彻底告别传统后台管理系统的单调色块，进入极具未来感与科技感的全息 HUD 视觉风格。
   - 无论在 PC 浏览器还是手机移动端，均呈现完美的比例与质感。
