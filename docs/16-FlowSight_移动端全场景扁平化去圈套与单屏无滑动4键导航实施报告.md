# FlowSight 移动端全场景扁平化去圈套与单屏无滑动 4 键导航实施报告

## 1. 设计哲学转变与痛点复盘

用户明确指出：
> “尽量扁平化，不要做做些圈圈套套，我认为反而会失去焦点，你觉得呢”
> “我想知道，你每个page的高度是怎么设定，我希望是全屏就够了，不需要做一个上下滑动，如果内容过多，我希望你可以做一个底部导航，做4个导航按钮。”
> “你的切片回放按钮和顶部的标题部件，都没有嵌入在页面内部，都严重错误，因此请思考这些地方，做成底部导航，不要做上下滑动操作”

### 1.1 核心问题诊断
1. **视觉噪音过大（“圈圈套套失去焦点”）**：
   - 此前尝试通过雷达旋转光圈、呼吸脉冲环、径向多层光晕、层层嵌套的卡片外框来营造“智能座舱感”，反而造成了视觉污染，用户一眼看过去无法聚焦在“当前在场几人”、“进出累计多少”、“时序峰值何时”等业务关键数据上。
2. **页面上下滑动沉长、控件脱离页面外层**：
   - 原看板将时序图、客群画像、回放入口、遥测数据全部纵向堆积在一页，用户必须反复上下滑动；
   - 顶部导航栏与底部导航栏使用了 Vant 的 `fixed` 悬浮机制，在移动端视口与桌面端中易脱离页面主机架，出现标题与内容断层、切片按钮滚出可视区的严重体验问题。

---

## 2. 扁平化极简主义与单屏纯平架构实施方案

### 2.1 彻底去除“圈圈套套”，回归扁平高对比度数据焦点
- **底盘与背景**：纯净深灰暗黑底盘（`#0A0D14`），彻底移除浑浊的径向光晕（Radial Mesh）和动态旋转光圈；
- **高对比度纯色色标**：
  - **瞬时滞留**：扁平电青 `#00D2FF`
  - **今日进入**：扁平薄荷绿 `#00E676`
  - **今日离开**：扁平赛博橙 `#FF9100`
  - **双向总流**：扁平晶紫 `#9D4EDD`
- **高反差大字号**：数据数值统一采用 `32px font-weight: 800` 纯白或亮色无投影实色字体，标签使用银灰 `#94A3B8`，对比度达到最高级无眩光状态；
- **纯平几何块面**：卡片采用 1px 细线边框（`#1E2636`）与干净的 6~8px 圆角，彻底移除模糊毛玻璃和复杂投影。

### 2.2 严格单屏 100dvh 无滚动架构（Zero-Scroll Full-Screen）
- **高度计算模型**：
  - 根容器：`height: 100vh; height: 100dvh; max-height: 100dvh; overflow: hidden;`
  - 核心视口宽度：`max-width: 430px; margin: 0 auto; display: flex; flex-direction: column;`
- **内嵌式布局（No Fixed Floats）**：
  - 顶部标题栏：通过 `flex-shrink: 0; height: 44px;` 自然成为主容器的第 1 个子元素，100% 嵌入页面内部；
  - 底部 4 键导航栏：通过 `flex-shrink: 0; height: 50px;` 自然成为主容器的第 3 个子元素，嵌入视口最底端；
  - 中间内容区域：通过 `flex: 1; min-height: 0; overflow: hidden;` 自适应填满剩余空间，彻底消灭全屏上下滚动条！

## 3. 四大功能导航矩阵（4-Tab Navigation）

我们将所有功能彻底分流为 4 个互不干扰、各自单屏满幅的专属控制台：

```
+-----------------------------------------------------------+
| [●] 万科物业未来城项目                          [ 退出 ]  | <-- 嵌入式顶部栏 (44px)
+-----------------------------------------------------------+
| 监控通道: [ 万科西区东门主入口  ▼ ]              [ 🟢 在线 ] |
+-----------------------------+-----------------------------+
| 瞬时滞留          [在场]    | 累计进入 (In)     [进场]    |
|   12 人                     |   128 人次                  |
| 当前通道内实时在场           | 当日累计进门总人次          |
+-----------------------------+-----------------------------+
| 累计离开 (Out)    [离场]    | 双向总客流        [汇聚]    |
|   116 人次                  |   244 人次                  |
| 当日累计出门总人次          | 进出双向总吞吐通量          |
+-----------------------------+-----------------------------+
| [✓] 通道通行状态与人流安全基线正常                        |
+-----------------------------------------------------------+
| 算法: YOLOv8 | 帧率: 30.0FPS | 时延: 14.2ms | 积压: 0同步   |
+-----------------------------------------------------------+
|  [⚡ 实时座舱]  [📈 时序走势]  [🎬 证据切片]  [👥 客群遥测]  | <-- 嵌入式底栏 (50px)
+-----------------------------------------------------------+
```

| 导航 Tab | 路由路径 | 核心业务定位 | 页面设计特性 |
| :--- | :--- | :--- | :--- |
| **Tab 1: 实时座舱** | `/dashboard` | 通道实时感知、4 大客流高能指标、安全基线、设备状态 | 单屏满幅、大字号聚焦、零上下滑动 |
| **Tab 2: 时序走势** | `/trends` | 5 维时间粒度切换、3 项核心摘要、采集时间动态流曲线 | ECharts 自适应填充剩余高度、实线对比、无滚动 |
| **Tab 3: 证据切片** | `/playback` | 条件检索控制台、事件流水、内嵌“播放”按钮、单行翻页 | 仅中间卡片列表内部轻量滚动，外层锁死单屏 |
| **Tab 4: 客群遥测** | `/insights` | 性别属性双色条、主力年龄段、推理总线遥测、切片管道规格 | 纯平 4 格遥测矩阵与规格参数明细 |
