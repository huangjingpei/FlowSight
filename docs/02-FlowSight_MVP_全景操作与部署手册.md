### SOP-01：【标定工作台】—— 空间 N 边形标定与参数微调
> **使用场景**：首次安装部署、摄像头位置变动、通道形状改变时的工程师专业操作。

```text
+-------------------------------------------------------------------+--------------------------------+
| [ 标定大画布：支持抓帧冻结 / 实时视频叠加 ]                        | [ 空间与算法标定工具箱 ]       |
| +---------------------------------------------------------------+ |                                |
| |                                                               | | 1. 区域绘制 (任意 N 边形):     |
| |       [1]*-------*[2]                                         | |    [ 新建多边形 ]  [ 清除 ]  |
| |         /         \  <-- 顶点放大为明显圆点，方便拖拽         | |    操作说明: 单击加点，双击闭合|
| |        /   ROI     \                                          | |    当前顶点数: 5 个点        |
| |      [5]*          *[3]                                       | |    几何状态: [ 合法凸多边形 ]|
| |          \        /                                           | |                                |
| |           *------*                                            | | 2. 防抖与状态机参数微调:       |
| |             [4]                                               | |    缓冲带宽度:  [--o---] 20 px |
| |                                                               | |    穿越确认帧:  [--o---] 4 帧  |
| | (虚线范围呈现缓冲带 Hysteresis Zone，可视化直观看到边界距离)  | |    事件冷却时间:[--o---] 30 帧 |
| +---------------------------------------------------------------+ |                                |
| [ 抓取当前帧作为静态底图 ]   [ 恢复实时预览 ]                     | 3. 生效控制:                   |
|                                                                   | [ 还原上次保存 ] [ 立即应用生效]
+-------------------------------------------------------------------+--------------------------------+
```

1. **进入工作区**：点击左侧导航栏的 **[ 空间标定 ]** 图标；
2. **抓帧或实时绘制**：
   - 可点击下方 **[ 抓取当前帧 ]**，在静止画面上从容打点；
   - 点击 **[ 新建多边形 ]**，鼠标在画面通道中依次单击打下顶点（支持 3 到任意多个点）；
   - 在最后一个点位置 **双击鼠标左键**，多边形自动闭合，变为半透明黄色蒙版；
3. **几何微调**：
   - 鼠标拖拽任意红色顶点控制球进行微调；
   - 鼠标在多边形内部按住左键拖动可整体平移；
4. **防抖参数调试**：
   - 根据通道宽窄，在右侧滑动调节“缓冲带宽度”（推荐 $20\text{ px}$）与“穿越确认帧”（推荐 $4\text{ 帧}$）；
   - 画布上直观以虚线呈现缓冲带，所见即所得；
5. **保存固化**：
   - 点击 **[ 立即应用生效 ]**，新 ROI 版本写入 SQLite，并同步热推送到【实时监控】页面。

## 4. 现场视角调优法则

| 视角类型 | 推荐相机仰角 | 代表点策略 | 缓冲带 $\delta_{\text{buf}}$ | 状态机确认帧 $K$ | 适用场景说明 |
|---|---|---|---|---|---|
| **走廊斜俯视（典型）** | $30^\circ \sim 45^\circ$ | **底边中心点**<br>`((x1+x2)/2, y2)` | $20 \sim 25\text{ px}$ | $4 \text{ 帧}$ | **标准走道**：脚底着地面清晰，使用默认推荐配置即可。 |
| **闸机垂直俯视** | $70^\circ \sim 90^\circ$ | **人体框几何中心**<br>`((x1+x2)/2, (y1+y2)/2)` | $10 \sim 15\text{ px}$ | $3 \text{ 帧}$ | **地铁窄门**：头肩为主无遮挡，中心点更稳，缓冲带收窄。 |
| **低机位平视视角** | $10^\circ \sim 20^\circ$ | **底边截断自适应点**<br>`((x1+x2)/2, y1+0.85h)` | $30 \sim 40\text{ px}$ | $5 \sim 6 \text{ 帧}$ | **桌面支架**：底部易截断，需自适应回退点并调大缓冲带。 |

## 6. 运维排障 Runbook

| 故障现象 | 可能诱因 | 现场应急排查与恢复手段 |
|---|---|---|
| **启动后报错找不到 `onnxruntime_providers_cuda.dll`** | 未拷贝 CUDA 运行库或驱动不匹配 | 检查程序目录是否包含该 dll；将 CUDA 安装目录下的 `bin` 加入系统 PATH 环境变量；应急可在配置中将 `use_cuda` 设为 false。 |
| **在【实时监控】页面无法画框标定** | 这是商用防误触机制 | 正常现象。请点击左侧导航栏切换至【空间标定工作台】进行区域编辑。 |
| **【证据回溯】页面双击无视频画面** | 缺少 `clips/` 目录写权限或视频解码器缺失 | 检查程序目录下是否有 `clips/` 目录；确保安装了标准 LAV Filters 或 Windows Media Player 解码包。 |
| **SQLite 报错 `database is locked`** | 未开启 WAL 模式或被其他工具独占打开 | 确保执行了 `PRAGMA journal_mode = WAL;`；关闭其他外部数据库查看工具。 |
| **画面出现大面积黑边且无法点击** | 窗口尺寸与视频比例不一致 | 正常现象。系统自动进行 Letterbox 居中，请在画面中央实际视频区域内单击标定。 |
